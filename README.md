# Giuseppe Lapietra – portfolio

The source of [peppe37.github.io](https://peppe37.github.io/): a single static page (HTML, CSS and a little JavaScript, no build step) in English and Italian.

- `index.html`: the page, with both languages inside it. The language follows the visitor's system, English by default, and the EN/IT switch remembers the choice.
- `assets/shots/`: screenshots of the projects.
- `assets/cv/`: the CV as PDF, in English and Italian. Rebuild them with `python3 scripts/build_cv.py` (needs Google Chrome); the data is in that script.
